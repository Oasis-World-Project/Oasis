# 好友

现在是怎么做的。为什么这么定，在 git 历史里。界面见《前端》§1、§2。

## 1. 账号资料（identity）

- **账号 ID**：注册时系统发的 8 位数字（随机、不重复、第一位不是 0），不能改；别人按它加好友。之前注册的账号迁移时补发。
- **资料**：名字（1–20 字，默认「用户」加账号 ID 后四位）、签名（60 字内）、性别（不说、女、男、其他）、地区（30 字内）、头像。
- **头像**：前端把选的图片裁成正中的方块、缩到 256 像素、转成 JPEG 再传（`PUT /v1/me/avatar`，内容是 base64）。服务端只收 PNG、JPEG、WebP（看文件开头的字节），最多 200 KB，直接存在 `users` 表里。头像地址 `GET /v1/users/:id/avatar?v=<版本>`：每换一次版本加一，换了就是新地址，所以响应可以一直缓存；没有头像时资料里的版本是 0，界面画名字的第一个字。
- **谁能看**：资料（不含邮箱）登录的人都能看——按账号 ID 查人（`GET /v1/users/lookup`，每人每分钟最多 20 次，记在这个 identity 进程的内存里）、按用户 ID 批量取（`POST /v1/users/profiles`）。别的服务取资料走 `POST /internal/profiles`。
- conversation 取来的资料在内存里留 30 秒（`service/profiles.ts`）：账号改名、换头像后，群里和私聊里最晚半分钟看到。identity 一时不通就用手上旧的。

## 2. 好友（conversation）

- **加好友**：先按账号 ID 查到人，再发申请（`POST /v1/friends/requests`，带一句 60 字内的验证消息）。对方同意（`POST …/requests/:id/accept`）后成为好友。重复申请只换验证消息；对方也申请过我，这一下直接成为好友。
- **拒绝、撤回**（`DELETE …/requests/:id`）：申请这一行真删除，对方不会收到「被拒绝」。
- **删好友**（`DELETE /v1/friends/:userId`，任一方都能删）：好友关系和两人的私聊（连消息）一起真删除。一起在的群不受影响。
- `GET /v1/friends` 一次给全：好友（带对方的资料、和他的私聊）、别人发给我的申请、我发出去还没回的申请。没有推送，私聊页每 15 秒读一次。
- 上限：一个人最多 500 个好友（`FRIEND_MAX`）、50 条发出去还没回的申请（`FRIEND_REQUESTS_PENDING`）。
- 表：`friend_requests`（谁发给谁、验证消息）、`friendships`（一对好友一行，小的用户 ID 在前）。

## 3. 好友之间的私聊

- 就是普通聊天：文字和文件，没有 AI。`POST /v1/friends/:userId/chat` 打开（没有就建），一对好友只有一个。
- 发文件：先传到 canvas（传的人名下），发话时带上（一句最多 10 个，可以不写字）。文件只跟着那条消息，没有群文件；两个人都能读（`GET /v1/groups/:id/attachments/:uploadId/content`，conversation 核对是成员、这条聊天里确实有这个文件，再向 canvas 取）。删好友时连同发过的文件一起真删除。
- 存成 `conversations` 里 `kind='direct'` 的一行，两个人都是它的成员（`group_members`）；`direct_key` 是两人的用户 ID（小的在前），保证只有一个。
- 读消息、发消息、推送用群的那一套接口（`GET /v1/groups/:id`、`…/messages`、`…/events`，见《群聊》§8），返回里 `kind` 是 `direct`。群才有的操作（改设置、叫 AI、拉人、踢人、群昵称、解散）对它一律 404；它也不在群列表里。

## 4. 群里的人

- **拉人**：群主把好友直接拉进群（`POST /v1/groups/:id/members`，或者建群时在 `members` 里一起给），不用对方同意；只能拉自己的好友，群员不能拉人。被移出的人群主可以再拉回来。新进群的人看得到之前的全部消息。
- **名字**：群里显示账号的名字。每个人可以给自己设一个群昵称（`PUT …/nickname`，空的就是不设），只在这个群里用。还在群里的人，之前说的话也跟着显示现在的名字；已经不在群里的，显示发那句话时的名字。
- 账号的名字在 `group_members.display_name` 里记着一份（AI 听群聊、发话时要用）：conversation 取到一个人的新名字时，把他在各个群、各个私聊里记着的名字一起改掉。
- 成员的先后：群主在前，其余按进群的先后。
