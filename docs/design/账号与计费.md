# 账号与计费

现在是怎么做的。为什么这么定，在 git 历史里（`git log -- docs/adr`）。

## 1. 登录和会话

- 邮箱加验证码，本地用 Mailpit 收信。验证码 6 位数字，10 分钟有效；同一邮箱 60 秒内只能发一次、每小时最多 5 次；每个验证码最多试 5 次。库里只存 HMAC（密钥 `AUTH_CODE_PEPPER`，绑定邮箱），比较用常数时间。
- 第一次验证就是注册。验证码核销、建用户、写 outbox 事件、建会话在同一个事务里。
- 会话令牌是 32 字节随机数，库里只存 sha256；默认 30 天，最多每小时续一次。只用 Cookie `oasis_session`（httpOnly、SameSite=Lax；`COOKIE_SECURE` 本地为 false，线上必须为 true）。前端拿不到令牌。
- gateway 负责鉴权：调 identity 的 `/internal/sessions/introspect`，结果按令牌哈希缓存 30 秒（`SESSION_CACHE_TTL_MS`）。所以退出登录后旧 Cookie 最晚 30 秒失效，这是有意的取舍。
- gateway 先删掉客户端传来的所有 `x-oasis-*` 头，再写入 `x-oasis-user-id`。Cookie 只转发给 identity。
- CSRF：写请求的 `Origin` 必须在 `GATEWAY_ALLOWED_ORIGINS` 里，否则 403。登录后的跳转地址只接受站内路径。

## 2. 额度

- 金额一律用微美元整数（1 美元 = 1,000,000）。
- 注册送额度：identity 写 outbox → `identity.user.registered` → billing 发放 `SIGNUP_GRANT_MICRO`（默认 30,000,000）。三层去重：消息 ID、`processed_events` 表、账本上的唯一索引。钱包还没建好时 `/v1/wallet` 返回 404 `wallet_not_ready`，前端稍等重试。
- 谁付钱由调用方在 `x-oasis-payer-id` 里指明。私聊由会话的主人付，任务由任务的主人付。

## 3. 每次调用怎么扣

模型调用、工具调用、算力都走同一套，都在 model-gateway 计量：

1. **冻结**：按价格表和输出上限估一笔，查不到价格用 `FALLBACK_HOLD_MICRO`。余额不够返回 402 `insufficient_balance`。
2. **调用**。
3. **结算或退回**：按实际花费结算，多冻结的退回。实际花费的来源按优先级：供应商返回的花费 > token 数 × 价格表 > 按字数估算；每次调用记下用的是哪一种（`cost_source`）。流断掉的调用凭生成 ID 向供应商查实际花费，不按字数估。

- 实际扣费 = 花费 × `BILLING_PRICE_MULTIPLIER`（默认 1.0），向上取整到微美元。超出余额的部分记为未收回，不会扣成负数。
- 失败就退回冻结。进程中途崩溃时，冻结超过 `HOLD_TTL_MS` 由清扫任务退回。
- 调用记录的 `kind`：`chat`（模型）、`tool`（工具）、`compute`（沙箱和检查容器的算力）。属于任务的调用结算后发 `model-gateway.call.settled`，task 把它累加到任务和成果上。
- 缓存：沙箱里的 dsh 每次调模型都带会话编号（`x-session-id`），model-gateway 原样作为 `session_id` 交给 OpenRouter，同一会话尽量固定在同一家供应商、吃得到上次的缓存。调用记录里记下这次输入有多少读的缓存、多少写进缓存（`cached_tokens`、`cache_write_tokens`）。Claude 这类要标缓存位置的，dsh 自己会标。
- 任务没有预算和上限：界面只显示已经花了多少，钱包余额用完才停。

## 4. 上游出错怎么说

上游拒绝的原因归成几类：地区限制（`provider_region_unavailable`）、限流（`provider_busy`）、其他（`provider_error`），界面据此给不同的提示。原始错误只写进日志和调用记录。流已经开始后出的错（供应商在流里报错、没收到完成标记就断了）也记进调用记录，带上 OpenRouter 把这次请求转给了哪家：同一型号在 OpenRouter 上有好几家在跑，各家的限制不一样。没配 Key 时模型调用返回 503 `provider_not_configured`。

## 5. 密钥

- 供应商的 Key（`OPENROUTER_API_KEY`、`TAVILY_API_KEY`、`FAL_API_KEY` 等）只放 model-gateway 的本地 `.env`，不进 git、日志、浏览器和沙箱。
- 沙箱里用的是每次运行一把的临时 Key：只能调模型和工具，花费记在这次运行上，运行结束就作废。

## 6. 删除

用户删除就是真删除，见《检查与交付》§8。保留的只有账本和调用、费用记录。
