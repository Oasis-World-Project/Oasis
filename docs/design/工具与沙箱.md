# 工具与沙箱

现在是怎么做的。为什么这么定，在 git 历史里（`git log -- docs/adr`）。

## 1. 沙箱

- 每次 AI 运行起一个容器，容器里只跑 dsh（精确锁定版本，经 stdin/stdout 说 JSON-RPC）。全仓只有 `services/harness/src/adapter/` 接触 dsh。工具节点跑的是 `oasis-steps`。
- 镜像：`oasis/harness-sandbox-base:<dsh 版本>`（`pnpm sandbox:build`）和带 Blender 的 `oasis/harness-sandbox-3d`（`pnpm sandbox:build:3d`）。规划时每样成果选一个环境。
- 默认 2 核 2 GB、最多 512 个进程（`SANDBOX_CPUS`、`SANDBOX_MEMORY_MB`）。没有显卡，3D 页面靠 CPU 画。
- 目录：`in/<上游节点>/`（上游交来的文件）、`materials/`（用户给的素材）、`out/`（要交出的文件）。输入和产出由 harness 拷进拷出，容器不直接访问对象存储。
- 网络：容器在内部网络里，不通外网。只能经入口代理访问 model-gateway 的 `/run/v1/*`（模型、工具），带着这次运行的临时 Key；经出口代理访问明确放行的软件包仓库（`SANDBOX_EGRESS_ALLOW_HOSTS`，npm 和 PyPI），所以 `npm install`、`pip install` 能用。碰不到任何服务的 `/internal`。
- 运行结束或取消时销毁容器、作废临时 Key。工作目录留在持久卷里，供继续和修改时接着原会话（见《任务与工作流》§4）。

### 预装的东西

写在镜像的 `/opt/oasis/software.txt`，`oasis-tool list` 会列出来；沙箱里有什么也写在 `in/.oasis-environment.json`。

| 用途 | 预装 |
|---|---|
| 网页、小游戏 | Node、Chromium、playwright-core、esbuild、typescript |
| 文档、数据 | LibreOffice、pandoc、poppler、sqlite3、jq，Python 的 pandas、openpyxl、python-docx 等 |
| 图片 | Pillow、ImageMagick |
| 字体（`/usr/share/fonts`，可以拷进成果或取子集后内嵌） | Noto CJK、Noto Color Emoji、点阵像素字体 Unifont（16×16，含中文） |
| 音视频 | ffmpeg、MLT（melt）、sox |
| 代码项目 | Python 3、git、ripgrep、zip、unzip、make、g++ |
| 3D（3D 镜像） | Blender、`oasis-3d`、`oasis_blender` 模块、`@gltf-transform/cli`、trimesh |

Chromium 的默认参数已经按沙箱的限制配好（非 root、`/dev/shm` 只有 64 MB、没有显卡），不带参数的 `chromium.launch()` 就能用。

## 2. 工具目录和调用

工具目录在 model-gateway（定义在 `src/service/tools/`，和供应商适配放在一起）：一个工具的名字、参数、调用方式和计费是一体的。没配 Key 的工具自动不可用。

- 沙箱里用命令行程序 `oasis-tool`（`services/harness/sandbox/oasis-tool.ts`）调用，例如 `oasis-tool image.generate --prompt "……" --out out/首屏.png`。不写成 dsh 插件，换掉 dsh 也照样能用。`oasis-tool list` 列出全部工具、用法和单价。
- 每次调用和模型调用一样：冻结额度 → 调供应商 → 按实际花费（拿不到就按目录单价 × 数量）结算 → 记调用记录 → 属于任务的调用发 `model-gateway.call.settled`，task 累加已花的钱。
- 供应商的 Key 只在 model-gateway。生成的文件由 model-gateway 取回，先存进自己的私有对象存储并校验，再交给 `oasis-tool`；沙箱不直连供应商。
- **长任务**（视频、音乐、3D、云渲染、提出调整）：提交后拿到任务号，`oasis-tool` 自己轮询，一条命令最多等 100 秒（`OASIS_TOOL_WAIT_SECONDS`），没等到就把任务号告诉 AI，之后用 `oasis-tool wait <任务号>` 接着等。等待期间不调模型。进度记在 `tool_jobs`，重启后接着查；同一个节点用同样参数重做时取回原来的结果，不重复生成。
- 参数定义一份几处用：`packages/contracts/src/tool-args.ts`、`ops.ts`。规划门、`oasis-tool`、`oasis-op` 用同一份检查参数。

现有的工具：

| 类别 | 工具 |
|---|---|
| 生成 | `image.generate`、`video.generate`、`audio.speech`、`audio.music`、`3d.generate`（图生 3D）、`3d.render`（云 GPU 渲染） |
| 看和听 | `media.inspect`（图片、视频、音频可以混着给，1 到 4 个文件）、`audio.transcribe` |
| 联网 | `web.search`、`web.fetch`（Tavily） |
| 判断和问 | `jev.decide`、`model.ask`（问另一个模型）、`text.batch` |
| 检查 | `app.check`、`website.test`、`android.test`（见《检查与交付》） |
| 工作流 | `workflow.adjust`（提出调整，见《任务与工作流》§5） |
| 本地操作 | `op.video.concat`、`op.video.trim`、`op.video.frames`、`op.video.audio`、`op.audio.concat`、`op.media.convert`：沙箱里的 `oasis-op` 用 ffmpeg 做，不花工具钱 |

`media.inspect` 的型号清单是 `TOOL_INSPECT_MODELS`，每个型号读得了哪几种文件照供应商目录；调用时只留读得了这次全部文件的型号。节点里的型号最多能直接看图，视频和音频都要用 `media.inspect`。

## 3. 别的模型怎么用

做成果的 AI 一直握着全部过程，别的模型被它叫来做一件事，结果交回它手里：

1. **当工具用**：上表里的生成、看和听、`model.ask`。`model.ask` 是一个问题加一段文字材料，拿回文字；对方只答这一次，看不到提问的 AI 的会话。能问的型号在 `TOOL_ASK_MODELS`。
2. **子 AI**：dsh 原生的 `subagent`，沙箱配置里开着，可以指定型号。什么时候用由做成果的 AI 判断。
3. **另一样成果**：只给互相独立的成果，各用各的沙箱，同时跑。

## 4. 型号

- 团队名单在 `services/agent/src/service/team-models.ts`，分三档（旗舰、强力、快速）。节点用哪个由规划员判断。
- **实测数据**：model-gateway 从调用记录里算每个型号最近 30 天的每秒输出 token、含缓存的实际单价、上游出错的比例（只算 agent 运行里的聊天调用，不到 30 次的不算），写进规划员的型号说明和 `model.ask` 的工具说明。开关是 `ESTIMATE_FROM_HISTORY`，开发环境默认关（开发库里混着假模型回归的记录）。哪个型号更擅长哪类活没有数据，不写。
- **「只用国内模型」开关**：按账号记住，在私聊输入框的「＋」菜单里，默认关。开了以后，给这个用户的 AI 团队列出的模型和各工具的型号都只留国内厂商的（名单 `DOMESTIC_MODEL_VENDORS`）；点名国外型号的工具调用在调供应商之前就拒绝（409 `model_out_of_scope`）。状态和过滤都在 model-gateway（表 `model_scopes`）。私聊里和哪个 AI 聊、平台自己的调用不受影响。
- 兜底（和开关无关）：节点运行碰上「地区不可用」换成默认型号接着做；私聊的 AI 在当前网络用不了时，接需求改用 `INTAKE_FALLBACK_MODEL`。

## 5. 给 AI 的话

给 AI 的说明只有三种：**事实**（有什么、多少钱、各自看得到什么）、**硬约束**（格式、上限、系统做不到的事、角色边界）、**用户的要求**（任务单、修改意见）。不写「尽量、宁可、只在…时才、够用就」这类把选择往一边推的话；背后有事实的改成只写事实，没有的删掉。

- 场景经验手册在 `services/agent/playbooks/*.md`（网页、文档、图片、音频、视频、3D、数字人等 11 份）。全部放进规划员的 `in/playbooks/`，说明里列名字和适用范围，由它自己挑着读。做成果的 AI 看不到手册，它要用的命令和格式由规划员写进它的说明。
- 交互网页、3D 预览等的文件格式写在 `in/.oasis-formats.json`。

## 6. 算力

harness 按沙箱容器实际存在的时长 × 核数 × 单价计费（`COMPUTE_PRICE_MICRO_PER_CORE_HOUR`，默认每核每小时 $0.015）。开容器前在 model-gateway 冻结，销毁后按实际时长结算，调用记录的 `kind` 是 `compute`。检查容器的算力同一套（见《检查与交付》§4）。

## 7. 音视频

- 配音、转写、生视频走 OpenRouter；生音乐走 fal（`FAL_API_KEY`，型号 `TOOL_MUSIC_MODELS`）。
- 大文件按流处理：canvas 上传直接流向私有桶，harness 流式读沙箱的 `out/`，较大的工具结果只给带归属和有效期的文件引用，`oasis-tool` 分块下载并核对哈希。
- 视频工程：交付可播放的 MP4 时可以附 Shotcut 工程（`project.mlt` 加 `media/` 素材，相对路径），用同一份时间轴生成工程和成片。

## 8. 3D 和云渲染

- 两条路线，AI 自己选：图生 3D（`3d.generate`，fal，型号 `TOOL_GEOMETRY_MODELS`），或在 3D 沙箱里用 Blender 写脚本建模。
- 3D 沙箱里的工具：`oasis-3d snapshot <模型>`（多视角图，Cycles CPU）、`oasis-3d check <模型>`（尺寸、贴地、网格问题、画布预览问题、glTF 校验）、`oasis_blender` 模块（材质、导出 GLB、取景、渲染）。
- 云 GPU 渲染（`3d.render`，Runpod）：GPU 侧只接受验证过的几何资产和声明式场景参数，由镜像里的固定入口构建和渲染，不接收任意脚本或镜像。扣款 = (执行秒 + 最多 90 秒延迟 + 5 秒空闲) × 锁定单价，封顶冻结额；GPU 失败退回冻结。只取回成品图。渲染 worker 镜像 `oasis/harness-render` 按不可变摘要拉取。
- 画布里交互预览 GLB；3D 导演台（视角、线框、网格、灯光、动画）只为看图。

## 9. 实时数字人

- 交付的是一份数字人配置（人设、开场白、知识要点、转人工规则、形象、声音、语言）。成果页点「开始对话」才开实时会话。
- 供应商是 LiveAvatar（FULL 模式：听写、配音、口型、形象由它负责），大脑接我们自己的模型：LiveAvatar 每轮调用 model-gateway 单独端口（`AVATAR_LLM_PORT`，默认 4118）上的 `/avatar/v1/chat/completions`，只认会话专用的临时 Key。公网只暴露这一条路径（开发期怎么暴露见 `docs/ops/云服务器.md`）。
- 计费：开始时按最长分钟数冻结，结束按实际分钟结算；大模型调用照常计量。浏览器关掉发不出「结束」时，model-gateway 的清扫任务查到会话状态后停止并结算。
