# ADR 0020：3D 工具、运行中消息即时送达、3D 导演台

状态：用户 2026-11-07 同意（「你接下来开始执行给 3D 任务准备好专用工具」「C」），实施中。

## 1. 问题

- 2026-11-07 两次马车任务里，节点在「想看一眼模型长什么样」上反复花时间：自己写相机和灯光脚本（一次把相机朝向写反，调了 6 分钟）、自己写回导检查（glTF 按法线拆点，误报开口边）、调了高光参数导致 GLB 带扩展、画布不能直接预览。Codex 也没有现成 3D 工具，但每个节点都重新踩这些坑没有必要。
- 超预算提醒和用户的运行中追问都走 dsh SDK 的 `session/prompt`，它只把消息排到「下一轮」（followup）。持续目标下一轮可能就是整个运行，第二次马车任务里两条提醒都等到运行结束才被看到。
- 3D 成果页（导演台）是一排文字按钮，也不能在画面上圈画批注：批注功能本身是通用的，只是 3D 预览没有提供「能画的画面」。

## 2. 决定

### 3D 工具（3D 沙箱镜像）

- `oasis-3d snapshot <模型> --out <目录> [--views front3q,side,front,back3q,top] [--size 960x720]`：读入 glb/gltf/fbx/obj/stl/ply/blend，按包围盒自动取景，加地面、三点光（太阳光）和中性背景，Cycles CPU 渲出各视角图，再拼一张 `sheet.png`。地面和灯光只为看图，不进模型。
- `oasis-3d check <模型>`：尺寸、最低点（是否贴地）、对象数、三角面、材质、焊点后的开口边/非流形边/孤立点/退化面、骨骼/形变/动画；GLB 还给出画布预览问题（与关卡同一份判定）和 Khronos glTF Validator 结果（`gltf-transform validate`）。
- Blender 辅助模块 `oasis_blender`（装进 Blender 自带的 modules 目录，脚本里直接 import）：`material`（只用基础色、粗糙度、金属度，导出不带扩展）、`export_glb`（不带相机灯光扩展和压缩，返回画布预览问题）、`stage`、`aim`、`render_views`、`load`、`survey`。snapshot/check 也用它，判定只有一份。
- 预装 `@gltf-transform/cli`（4.5.1，带 glTF Validator）和 Python `trimesh`（5.2.0）。
- 3D 手册和 `in/.oasis-formats.json` 的 `model3d` 各写一行告诉节点这些工具存在。

### 运行中的消息在当前这一步送到

- 沙箱里的 `node-goal` 插件：根会话这一轮还开着时，来自用户的新消息（SDK 的 followup，source 为 user）从「下一轮」挪到「下一步」（dsh 的 steer 边界），持续目标下的长回合也能马上看到提醒和追问。
- harness 的 dsh 适配器不再按「一条消息一轮」数：消息进了会话历史就算收到，之后要等到它所在那一轮的结束通知才算处理完；没有结束通知仍按失败处理。

### 3D 导演台（桌面端为准，ADR 0019）

- 文字按钮换成浮在画面底部的图标工具条：放大、缩小、适配画面、复位；线框、地面网格、坐标轴（开关）；灯光（弹出亮度、色温两排选择）；有动画时加播放/暂停和片段选择。旋转、平移交给鼠标（拖动、Shift + 拖动）。
- 右上角视角块：顶、前、斜、左、后、右，一点就切。
- 查看器新增地面网格（铺在模型底面，颜色取主题次要文字色）和坐标轴，默认关，只为看图；释放时一并回收。
- 顶栏的「交互预览 / 静态预览」改成一个分段开关；底部说明压成一行（操作提示 + 大概尺寸），检查范围收进折叠。
- 3D 批注：成果页把 3D 模型和运行中的网页一样当成「截下当前画面再圈画」的画面。桌面端截下此刻的视角（截图时先藏起视角块和工具条），在截图上用笔、圈、编号标注后发给 AI；浏览器里仍只能写文字意见（ADR 0019 不再为浏览器补）。

## 3. 验证

- harness 单元测试覆盖适配器的新计数方式（消息插进当前轮、缺结束通知仍失败）。
- `pnpm sandbox:build && pnpm sandbox:build:3d && pnpm sandbox:check:3d`：在真实 Blender 里验证 oasis_blender 导出可预览 GLB、snapshot 出图和拼图、check 焊点后无误报开口且 glTF 校验通过。插件的即时送达要在真实任务里看（运行中追问后，运行事件里应立刻出现那条用户消息）。
