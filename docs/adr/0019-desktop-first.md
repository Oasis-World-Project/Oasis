# ADR 0019：以桌面端为准

状态：用户 2026-11-07 决定（「这个项目其实基本放弃网页端了，只考虑桌面端，网页端随便糊弄一下就行了，也是为了减少开发压力」），已采纳。

## 1. 决定

- 产品面向 Electron 桌面窗口。功能设计、实现和验收都以桌面端为准。
- 桌面端加载的就是 `apps/web` 这一套界面，所以前端代码仍只有一份；变化在于取舍：用浏览器直接打开只需能用，不为浏览器单独做降级、兼容或专门功能，也不把「浏览器里做不到」当成限制（例如截图只在桌面端能做，就按桌面端设计，浏览器里不另做退路）。
- 已有的浏览器退路（如应用截图批注在浏览器里退化为文字意见）保留现状，不再维护或扩展。

## 2. 同步的文档

- `AGENTS.md` 前端约定加一条「以桌面端为准」。
- `README.md`：`pnpm desktop` 不再标「可选」，说明产品以桌面窗口为准。
- 历史 ADR 里「桌面版」「浏览器退化」等表述照旧保留作记录，以本 ADR 为准。
