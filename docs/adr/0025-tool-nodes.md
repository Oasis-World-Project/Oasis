# ADR 0025：工具节点——不用 AI，按写好的步骤调工具

状态：已采纳（执行方案阶段 4，用户 2026-11-08 确认方案）。

## 1. 起因

- 很多步骤事先就定得下来：按分镜逐个生成视频、把几段拼成成片、转格式、抽帧、配音轨。让 AI 节点去做，要付一整段对话的钱，还可能跑偏（漏一段、参数写错、多生成几次）。
- 拼视频、转格式这类确定的本地处理，AI 节点每次都要自己现写 ffmpeg 命令，写错了就返工。

## 2. 决定

1. **新的节点种类 `tool`。** 方案里写 `steps`：每步 `{tool, args, out}`，按顺序执行，最多 12 步。
   - `tool` 是工具目录里的工具名：外部工具（`video.generate`、`image.generate`……）或沙箱里的本地操作（`op.*`）。
   - `args` 和沙箱里 `oasis-tool <工具> --名字 值` 一一对应；文件写沙箱里的路径：上游交来的 `in/<上游 key>/…`、用户素材 `materials/…`、前面步骤的结果 `out/…`。参数名不能是 `out`（写在步骤的 `out` 里）、`new`（重试由执行器决定要不要重新提交）。
   - `out`：结果存到 `out/` 下哪里。文字结果的工具（搜索、看图、转写、判断）给了 `.txt/.md/.json/.jsonl/.csv` 的 `out` 就把工具说的话存进去；该有文件却没生成算这步失败。图片工具按供应商实际格式存（要 `.png` 回了 JPEG 会存成 `.jpg`）时，执行器用 `oasis-op media.convert` 换回 `out` 写的格式、删掉原来那份，换不成算这步失败——下游按计划里的路径取文件（2026-11-08 真实小样：关键帧存成 `frame.jpg`，镜头视频找不到 `frame.png`）。
   - 工具节点不用模型（库里 `model` 为空字符串），不收追问；节点配置 `ToolConfig.steps`；`nodes.kind` 放宽到 `tool`（expand 迁移 `20261108160000`）。
2. **执行：harness 起工具运行，不起 AI。** task 交给 harness 的运行 `model` 写 `oasis/tool`、带 `steps`；harness 不按模型目录准入，改要执行环境有 `tool-steps` 能力（镜像里有执行器，旧镜像准入就拒绝并提示 `pnpm sandbox:build`）。沙箱跑的是 `oasis-steps`（代替 dsh），其余流程（临时 Key、算力租约、存产出、停止、接管、继续）和 AI 运行完全一样。
   - 执行器按顺序调 `oasis-tool` / `oasis-op`，往 stdout 写一行一个 JSON（`tool_call`、`tool_result`、`assistant_text`、`done`），harness 记成运行事件，工作流页照常显示过程。
   - 每步失败自动重试 2 次（等 10 秒、20 秒）：供应商明确没做出来（没收费）或旧结果已过期的加 `--new true` 重新提交；批次接着原来的进度；结果没确认的长任务不再试（重新提交可能重复收费）；其余照原样再试——做到一半的长任务由 oasis-tool 接着原来的提交。还不行节点失败，和干活节点一样交给用户处理。
   - 长任务（视频、音乐……）一直等到做完：oasis-tool 每次最多等 10 分钟，没好就接着 `wait`。
   - 进度记在工作目录里 `out/.oasis-steps/progress.json`（步骤摘要 + 做完的步骤）：接管、停止后继续、失败后再试时跳过做完的步骤；步骤改过就从头做。进度和中间文件不算成果、不传给下游。
3. **本地操作 `op.*`：沙箱里的 `oasis-op`，用 ffmpeg 做，不调供应商、不花工具钱、只占沙箱算力。** 进工具目录（`local: true`，一直可用），工具节点和干活节点里的 AI 都能用（`oasis-op …` 或 `oasis-tool op.…`）。

   | 操作 | 做什么 |
   |---|---|
   | `op.video.concat` | 按顺序拼几段视频：统一画面大小（等比缩放补黑边）和帧率，没声音的段补静音 |
   | `op.video.trim` | 截一段（按秒，精确到帧） |
   | `op.video.frames` | 抽帧：每隔几秒一张，或在几个时间点各一张 |
   | `op.video.audio` | 配音轨：替换原声或和原声混合，成片按画面长度 |
   | `op.audio.concat` | 拼几段音频（统一 48 kHz 立体声） |
   | `op.media.convert` | 按 `--out` 后缀转格式，可顺带缩放；视频转 `.gif` 做动图预览 |

4. **工具参数一份定义几处用。** `packages/contracts/src/tool-args.ts`（参数的形状和检查）、`ops.ts`（本地操作）；model-gateway 的每个工具写 `cli`（命令行参数）和 `per`（计费单位数在哪个参数里），工具目录返回 `args`、`per`、`local`。
   - 规划门按目录检查工具节点的每一步：工具在不在、参数（必填、范围、选项、文件路径）、型号能不能用；`text.batch` 在工具节点里要写 `model`。
   - 步骤直接引用的上游文件（参数里的 `in/<上游>/…`）：要有连线，并自动成为上游必须交出的文件（`expects`）——上游没交出来，关卡让它改一次，不等工具节点开跑才发现缺文件。修改时上游沿用的，要求它上一版确实交出过。
   - 沙箱镜像里按仓库的相对位置放这两个文件（`/opt/oasis/packages/contracts/src/`），oasis-op 执行前用同一份定义检查参数。
5. **估价 = Σ 每步工具单价 × 计费单位数 + 一次沙箱算力。** 计费单位按目录的 `per`（视频按 `duration` 秒、生图按 `n` 张），没写用默认值；本地操作不算工具钱。
   - 单价随参数变的按这一步写的参数取：目录的 `ToolRate.by` 列出参数值 → 单价（视频按 `resolution`，来自供应商的分清晰度价格），没写或表里没有用默认单价（视频是 720p 的）。真实小样里 480p 的视频原先按 720p 估、高估一倍；1080p 会低估一倍。规划员看到的工具单价也列出各档。
6. **和 AI 节点不同的地方（节点种类插件的三个开关）。**
   - `reworkable: false`：关卡没过不返工（没有 AI 能改），带着提醒往下走；整体验收缺文件时不让它自己补，只在上游补好后跟着重跑；修改意见、验收补文件落到它身上时拿上游最新产出重跑一遍。
   - `switchable: false`：不按「模型地区不可用」换模型。
   - `listens: false`：不收追问和补充要求（接口 409，页面不显示输入框）。
   - `continuable: false`：修改时只能沿用或重新做。
7. **工作流页**：工具节点显示齿轮、不显示 AI 头像，卡片写「N 步：工具…」，详情列出每一步（工具、参数、结果路径）；编辑节点时可以新建工具节点、用 JSON 改步骤；运行过程里 `oasis-op` 的调用记成对应的 `op.*` 工具。

## 3. 没做的

- 步骤之间不并行；分支、循环、按上游清单展开（「一个镜头一支」）留给阶段 5 的子节点机制。
- 同一个工具节点用同样参数重做时，长任务由 oasis-tool 的稳定幂等键（按节点）取回原来的结果，不会再生成一份新的；要不同的结果就改参数（阶段 5 的「做 N 版挑 1」用不同的种子）。

## 4. 验收

- 单元测试：执行器（命令拼法、重试规则、长任务等待、文字结果、进度接续）、oasis-op 参数检查、harness 工具运行（不起 dsh、失败原因、准入、停止后继续、契约）、规划门（参数、引用的上游、重名结果、估价、上游 expects）、工具目录参数和网关实际参数一致、工作流页。
- `pnpm sandbox:check:ops`：沙箱镜像里离线现做素材，6 个本地操作和 `oasis-tool op.*` 各跑一遍，再用执行器跑一个只有本地操作的工具节点、确认第二次跳过做完的步骤。
- 回归场景 `toolnode`：规划员排一个 3 步的工具节点（两段 `video.generate` + `op.video.concat`），节点不调模型、视频提交两次、harness 里是工具运行、过程是三条命令、关卡解码检查通过、画布里只有成片且是重新编码的。2026-11-08 全量回归 12 个场景全过。
- 真实小样 `pnpm e2e --real real-tool`（2026-11-08，花费上限 $2）：请求是用户口吻的一段话（两段 4 秒的镜头、alibaba/wan-3.0、480p、16:9，再按顺序拼成成片），真规划员（deepseek-v4-pro）排了一个 3 步工具节点，型号、时长、清晰度、比例照写，提示词自己补全；沙箱不起 AI 依次执行，两段视频各约 2.5–2.7 分钟，`oasis-op video.concat` 拼成 8.08 秒、854×480 的 H.264 + AAC 成片；任务约 6 分钟交付。一共 $0.4687：视频 $0.425、规划 $0.041、接需求 + 算力 + 解码检查不到 $0.003。估价 $0.80（按 720p 单价），由此补了第 5 条的按清晰度估价。
