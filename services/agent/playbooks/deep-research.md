# 深度研究

> 适用：竞品研究、行业分析、情报简报、财报或资料综述，以及需要可追溯引用的报告。

- 先拆研究问题，独立问题可并行查资料，最终汇总观点和证据；不要预先规定节点数量。
- web.search 找来源，web.fetch --out out/资料 保存网页全文；抓取失败、正文缺失或超限须记录，不能只凭摘要伪造引用。PDF 链接读取能力需真实预检，失败时使用用户上传资料。
- 来源.json 记录来源 ID、标题、网址；本地 PDF 记录文件名和页码。每个关键结论标 [n] 并对应来源，区分事实、推断和未知。
- 同一指标出现冲突时单列“指标冲突”，注明口径、时间、单位及采用理由；没有冲突也说明核对范围。
- 视频引用必须有实际转写时间戳或已验证的分段起点加偏移；纯文字转写不能推断精确时间，也不能声称支持时间引用。
- audio.transcribe 的 language 指源音轨语言，不是报告语言；不确定时省略，让模型识别。英文音轨用 en，转写后再写中文报告。长静音段不能凭识别幻觉添加内容，日期和金额失真时先核对语言参数，不反复调整音量掩盖问题。
- 现有转写不返回时间戳时，用 ffmpeg 的 segment 模式按约 30 秒导出音频段，同时用 `-segment_list` 输出 CSV 起止时间表。每段单独 audio.transcribe，把正文与该段实际起止时间绑定，引用写时间范围（如 00:30–01:00）；不杜撰范围内的秒级时刻。工具 uses 按分段数估计并记录逐次费用。保留源文件、分段表和转写来源对应关系，实际引用须以核对过的时间表为准。
- HTML 与 PDF 尽量从同一份内容生成，用 WeasyPrint 导出 PDF；deliver 包含最终报告、来源清单和必要附件，原始抓取稿是否交付以任务单为准。
