# 3D 模型、场景与渲染出图

> 适用：三维模型、房间/展厅/展台等空间布局、产品或道具的 3D 资产、布光渲染出图、把参考图变成 3D 模型。

- 沙箱有 Blender（只有 CPU，渲图只够自己看效果，Cycles 要关掉降噪）。也可以用 `oasis-3d`：写一份 `scene.json`（字段见 `oasis-3d --help` 和 `/opt/oasis/geometry.py`）一键生成 `.blend` + GLB 工程。
- 图生 3D：`oasis-tool 3d.generate --image 参考.png`，不保证真实尺寸和背面。
- 云 GPU 正式渲染：`oasis-tool 3d.render --scene <oasis-3d 工程>/scene.json`。用户没要渲染图就不用。
- 画布能直接交互预览的只有自包含 GLB（限制见 in/.oasis-formats.json 的 model3d）。其他格式要预览，用 `oasis-3d preview 模型.glb` 生成配套预览文件。
