# 3D 模型、场景与渲染出图

> 适用：三维模型、房间/展厅/展台等空间布局、产品或道具的 3D 资产、布光渲染出图、把参考图变成 3D 模型。

- 先确认用途（外观概念、可编辑布局、成品展示图）、单位（米）和哪些尺寸、数量、位置是硬约束。精密 CAD、可制造尺寸、拓扑/绑定、可打印性不是默认保证；用户提出时如实说明现有能力是否够，不把概念模型说成工程设计或真实测量。
- 两条路线按需求选，可以组合：尺寸、数量、相对位置明确的布局（房间、家具、展台）用沙箱里的 `oasis-3d` 写 `scene.json` 程序化建模，尺寸可核对；只要外观像某张参考图的单个物体，用 `oasis-tool 3d.generate --image materials/参考.png --resolution 1024 --out 临时目录/模型.glb`（图生 3D，按次计费，不保证真实尺寸和背面），再作为 asset 放进场景并按真实尺寸缩放。没有参考图时可以先 `image.generate` 再生成，两步费用都要算进预估。`oasis-tool list` 核对当前可用工具和价格。
- `scene.json` 版本 1，单位米，Z 轴向上，`position` 是物体中心，`rotation` 为角度：`objects` 里 box/sphere/cylinder 用 `size [x,y,z]`、`color [r,g,b,a]`、`roughness`、`metallic`、`emission`（0–100 自发光，用于灯罩、屏幕等，颜色取 color）；`kind:"asset"` 引用 `assets` 里的 GLB（`id`、相对 `path`、实际 `sha256`、`origin` 来源说明），不能覆盖其材质。`camera {position,target,lens}`；`lights` 最多 8 盏面光 `{position,target,power(瓦),size(米),color[r,g,b]}`，暖光如 `[1,0.75,0.45]`；`background` 是环境颜色，夜景用接近黑的深色。字段以 `/opt/oasis/geometry.py` 为准，未知字段会被拒绝。
- `oasis-3d build scene.json --out out/工程`（必须是新目录）生成 `scene.blend`、`model.glb`、`scene.json`、`assets/`、README 与 manifest；`oasis-3d inspect out/工程` 核对闭包和摘要；`oasis-3d pack out/工程 --out out/工程.zip` 打包。改了就换新目录重建，最终只交一套。
- 布局要用数字核对：从 `scene.json` 算出并写明关键约束（贴墙距离、通道净宽、门的位置和开口、物体之间不重叠、不穿墙），不能只凭看图。墙体用薄 box 搭建并给门留出空位。
- 出图分两级：沙箱里的 Blender 只有 CPU，只用于草渲检查构图（静帧会被自动限制在 640×480、32 采样以内，不能当成品）；正式图用 `oasis-tool 3d.render --scene out/工程/scene.json --width 1280 --height 960 --samples 64 --out out/渲染.png`，在云 GPU 上用同一场景渲染，返回 PNG 和与之一致的工程 ZIP（保存路径以命令输出为准）。GPU 同一时刻只接一个作业，忙时会被拒绝：等一会儿再试，不要循环提交；一个任务通常只做一次最终 GPU 渲染。超过等待时间按提示用 `oasis-tool wait`。草渲图不能冒充 GPU 成品。
- 交付：`model.glb`、工程目录或 ZIP（含 `scene.blend`、`scene.json`、`assets/`）、要求的渲染图，以及简短说明：哪些约束已用数字核对、哪些未检查（外观质量、真实可制造性等）、用了哪些生成/渲染工具。渲染图与工程必须来自同一份 `scene.json`。
- 预览：画布能交互查看不超过限制的自包含 GLB（≤16 MiB、20 万顶点/三角面、仅 PNG/JPEG 贴图、无扩展）。`oasis-3d build` 发现 `model.glb` 超限（如生成资产面数多、WebP 贴图、自发光扩展）时，会在工程目录自动生成简化的 `model-preview.glb` 和 `oasis-model-preview.json`；交付时把 `model.glb`、`model-preview.glb`、`oasis-model-preview.json` 一起列入 deliver，用户点开 `model.glb` 就能拖动查看。直接交付 `3d.generate` 的原始 GLB 时，先 `oasis-3d preview 模型.glb` 生成同样的预览文件并一起交付。不要手改这两个文件（摘要会对不上）。只交 `.blend` 或 ZIP 时，同时交付 `model.glb` 及其预览，用户从 `model.glb` 查看。
