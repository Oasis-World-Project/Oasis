# 合成数据

> 适用：问答数据集、领域合成样本、微调数据、批量生成、质量评分与过滤。

- 从用户资料提取主题和可核对事实作为种子，再生成稳定 id 的 JSONL 提示；不要在缺少来源的情况下编造领域事实。
- text.batch --in 提示.jsonl --out out/生成.jsonl 按行生成；jev.decide --in 评分问题.jsonl --out out/评分.jsonl 按行评分。二者都显式设置预算，每行独立计费，uses 按行估算。
- 中断后同一 --out 加 --resume true；失败和结果不确定的行不会自动重发。需要重试时先核对已有费用，再另建输入与输出，避免重复收费。
- 每行验证必填字段、类型和内容长度，用代码做精确与近似去重，再按评分阈值过滤。最终要求“至少 200 条”时统计过滤后的有效行，不能把文件数量或生成尝试数当成样本数量。
- 用 pandas/pyarrow 导出 JSONL/Parquet，并读回核对模式和行数。交付统计报告：生成数、失败/不确定数、去重数、各过滤原因、最终数量、分数分布及抽样最多 20 条。
- deliver 只列最终数据集及统计报告；批次检查点、提示、原始候选与逐行评分中间文件不自动交付。
